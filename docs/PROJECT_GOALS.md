# Matter Ubuntu Lab — Project Goals

## 목적

Ubuntu PC에서 Matter를 처음부터 실제로 실행하고,
실험 결과에 근거하여 Matter / Multi-Admin / Bridge /
Local AI 연동을 단계적으로 검증한다.

## 현재 상태

Matter 경험:
없음

현재 장비:
Ubuntu PC 1대

현재 물리 Matter Device:
없음

## 단기 목표

1. Linux virtual Matter Device 실행
2. CHIP Tool 실행
3. Commissioning
4. Endpoint / Cluster / Attribute / Command 이해
5. OnOff 등 기본 Cluster 제어
6. Multi-Admin alpha/beta
7. 두 Fabric에서 같은 Device 상태 제어 및 관찰
8. Linux Matter Bridge
9. Bridged Endpoint
10. local decision → Matter 연결

## 장기 목표

Matter AX Sprint 2026 본선에서

Matter 구현 완성도
+ Multi-Admin / 복수 Controller
+ Local AI

가 하나의 안정적인 end-to-end prototype으로
동작하도록 한다.

## 핵심 원칙

아이디어보다 먼저 Matter 기반을 안정화한다.

추측보다 실제 실행결과를 우선한다.

한 번 성공한 connectedhomeip revision을
이유 없이 변경하지 않는다.

실패와 성공을 모두 기록한다.
